Four opt-in layers, each off by default. With them off, `Memory` behaves as it did in 0.1.2.

- **[Context graph](/docs/context-graph/)** (`context_graph`): memories linked by replies, timeline order, shared documents, and topic similarity, with graph-first search (BFS or PageRank), decay, optional LLM-labelled edges, snapshot and replay, and a change feed you can send to a webhook, SSE, or Kafka.
- **[Personalized retrieval](/docs/personalized-retrieval/)** (`mspr`): feedback, usage, past-success, and intent signals in the ranking, and role policies.
- **[Tenants](/docs/tenants/)** (`tenant`): a registry of tenants, sub-tenants, and roles, with export, import, migrate, and delete.
- **[Decay and versioning](/docs/decay-and-versioning/)** (`decay_v2`): decay scores, archiving, a background scheduler, reference tracking, and cold storage on disk or S3.

Also:

- `history_db_path` accepts a Postgres URL.
- Graph memory (TCMGM): faster fused search, rules-first causal extraction with an LLM fallback, a circuit breaker that falls back to rules when the LLM fails, and optional larger CLIP / SigLIP image models with fp16 or int8 quantisation. Importing the package no longer loads torch or transformers.
- Fixed: the `anthropic` provider now sends only `temperature`, so Claude 4.x models (Haiku 4.5, Sonnet 4.6, Opus 4.6) work. See [Providers](/docs/providers/#llms).
- Fixed: adding images with vision on keeps the JSON-mode contract.
