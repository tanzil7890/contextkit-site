This is ContextKit→

A memory layer for AI agents. Instead of resending the whole conversation every turn, your agent stores facts once and pulls back only the handful that matter for the request in front of it.

Memory your agent can actually use

Facts, not transcripts

An LLM pulls durable facts out of each conversation and decides whether each one is new, an update, or something to forget. Pass infer=False to store text as-is.

Your models, your store

15 LLM providers, 10 embedders, and 16 vector stores, from OpenAI and Ollama to pgvector and Pinecone. Qdrant on local disk runs with no servers at all.

Scoped by default

Every memory belongs to a user_id, agent_id, or run_id, and every search is narrowed to one. Add your own metadata and filter on it.

Ask when and why

Add Neo4j, Memgraph, or Neptune and memories gain entities, a timeline, and cause → effect links, so use_tcmgm=True can answer “what changed before it broke?”

Privacy building blocks

Find emails, phone numbers, API keys, and anything you write a rule for, redact them before they are stored, and encrypt values with AES-256-GCM or Fernet.

Every change on record

Each add, update, and delete writes a history row, so history(memory_id) shows how a fact changed over time.

Memory as a graph{{ "next release" if coming else "opt-in" }}

Every memory becomes a node, linked to the memories around it. Search starts from the closest matches, walks the links, and re-ranks what it finds with signals that learn from feedback.

query→ seed · dense + keyword→ expand · BFS or PageRank→ re-rank · graph, feedback, usage→ top memories

Context graph

Replies, timeline order, shared documents, and similar topics are linked as you add. Snapshot the graph, replay its change log, or stream changes to a webhook, SSE, or Kafka.

Personalized ranking

Feedback, usage, and answers that worked before each add a weighted signal to the score. Every weight starts at zero, so nothing changes until you turn one up.

Tenants and lifecycle

A tenant registry with sub-tenants and roles, plus decay scores that archive stale memories and move them to cold storage on disk or S3.

Get started

  1. Install with the command above. Python 3.9 or newer.
  2. Set a model key: export OPENAI_API_KEY=sk-…. OpenAI is the default; Anthropic, Gemini, Groq, Ollama, and others are a config change away.
  3. Store what the user says with memory.add(messages, user_id="alice").
  4. Search before each reply with memory.search(query, user_id="alice"), and put the results in your prompt.
