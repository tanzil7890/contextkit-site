How it works

The life of a memory

Two calls do most of the work: add when something is said, and search before your agent answers. Everything else is an option on one of them.

  1. 01

    Remember

    An LLM reads what was said and keeps the facts in it. Each one is compared with what is already stored, then added, merged into an existing memory, or left out.

    memory.add(messages, user_id="alice")

    Pass infer=False to store text exactly as written.

    alice · Mar 02

    “I'm vegetarian, and I'm allergic to peanuts.”

    • +Is vegetarianADD
    • +Allergic to peanutsADD
  2. 02

    Revise

    When a fact changes, the memory is updated instead of contradicted. The old text is kept on record, so you can see how a fact changed and when.

    memory.history(memory_id)

    alice · Apr 07

    “I've started eating fish again, by the way.”

    • −Is vegetarian
    • +Eats fish, no other meatUPDATE
    history(memory_id) Mar 02ADDIs vegetarian Apr 07UPDATEIs vegetarian → Eats fish, no other meat
  3. 03

    Recall

    Before each reply, search one person's memories and put the best few in the prompt. Searches never leave the scope you give them.

    memory.search(query, user_id="alice", limit=3)

    Turn on the context graph and the memories linked to a match come back with it.

    alice · Apr 28user_id = alice

    “Any idea what I could cook tonight?”

    1. 0.82Allergic to peanuts
    2. 0.79Eats fish, no other meat
    3. 0.61Cooks quick weeknight dinners

    agent, with 3 memories in the prompt

    Grilled salmon with lemon over a quick quinoa salad. I've left out satay sauce and peanut oil because of your allergy.

  4. 04

    Forget

    Memories nobody uses fade. With decay on, each memory gets a score from 0 to 1 for how recently and how often it was used and whether it helped. The lowest are archived to disk or S3 until they are needed again.

    memory.archive_low(threshold=0.1)

    When someone asks to be forgotten, memory.delete_all(user_id="alice") removes their memories. Decay is an opt-in layer.

    score = 0.6 × recency + 0.3 × use + 0.1 × feedback

    • Allergic to peanuts0.94used 3 days ago · 12 uses · 2 helpful
    • Cooks quick weeknight dinners0.45used 40 days ago · 3 uses
    • Training for a 10k in May0.06last touched 200 days ago · never usedARCHIVED

Kinds of memory

An agent remembers different things for different lengths of time

Each kind is a scope or a feature of the same library, so you can mix them in one store.

User memory long-term

Preferences, constraints, and history about a person that should outlive any one conversation.

user_idAllergic to peanuts

Session memory one task

What matters for one ticket or run, and nothing else. Clear it when the job is done.

run_idWants the refund on the original card

Agent memory shared

What one agent learned across the people it serves, or what several agents share on one job.

agent_idLogin builds SQL by concatenation

Procedural memory how-to

How the agent got something done, summarised from its own steps, so the next run goes faster.

memory_typeSearch → refundable only → hold seat

Episodic memory events{{ soon("episodic-memory") }}

What happened, when, and what led to what: dated events with cause and effect links.

build_timelineCache shipped Mon → timeouts Tue

Relational memory entities

People, products, and services and how they connect, kept in Neo4j, Memgraph, or Neptune.

graph_storealice → works_at → acme

Document memory reference

Handbooks, transcripts, and logs stored as written, split into chunks, rejoined when found.

infer=FalseRefunds within 30 days of delivery

Visual memory images

Screenshots, photos, and designs, described by a vision model and kept as searchable facts.

enable_visionSpring packaging is sage green

Common combinations of kinds of memory and layers.

Support agents

Remember each customer's products, past tickets, and preferences, so nobody explains twice. Answers marked helpful rank higher next time.

Get started

Four steps to an agent that remembers

  1. Install with {{ library.install }}. Python 3.9 or newer.
  2. Set a model key with export OPENAI_API_KEY=sk-…. OpenAI is the default; Anthropic, Gemini, Groq, Ollama, and others are a config change away.
  3. Store what the user says with memory.add(messages, user_id="alice").
  4. Search before each reply with memory.search(query, user_id="alice"), and put the results in your prompt.
